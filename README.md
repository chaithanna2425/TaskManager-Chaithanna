# Task Manager

Developed by: Chaithanna

## About the Project

This is a Task Manager web application made as a full-stack CRUD project.

I built the frontend using React and the backend using Django REST Framework. MySQL is used to store the task data.

## Features

- Register and login
- Add a task
- View tasks
- Edit tasks
- Delete tasks
- Change task status
- Add due dates
- Search tasks
- Filter tasks
- View task progress
- Logout

## Technologies Used

- React
- JavaScript
- CSS
- Django
- Django REST Framework
- MySQL

## CRUD

The application supports all four basic CRUD operations:

- Create - Add a new task
- Read - View tasks
- Update - Edit a task
- Delete - Remove a task
